SEATTLE EVENT GROUP WEBSITE

Extract this ZIP and open main.html in a browser. No build tools required.
Keep HTML, CSS, JavaScript, and the three JPG files in the same folder.

main.html - content and slide images
styles.css - design, responsive layout, and hero gradient
script.js - slideshow controls and timing (INTERVAL_MS = 6500)

The hero crossfades every 6.5 seconds; pause, previous, next and direct selection controls are included. Autoplay pauses on hover, keyboard focus, and hidden tabs. Reduced-motion preferences disable autoplay by default.
Photos fill the hero with responsive cropping; change object-fit: cover to contain if you prefer uncropped images with empty space around them.

All three images are AI-generated event inspiration, not photographs of company work. Replace them with your own photos when available. Google Fonts requires an internet connection; local fallback fonts work offline.
Booking is marked coming soon. There is no connected inquiry form.
