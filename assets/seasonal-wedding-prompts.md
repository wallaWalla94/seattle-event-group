# Seasonal wedding scenes

Generated with the built-in Imagegen tool. Summer uses the original `weddings.png`. The other seasons change the venue, nature, linens, flowers, table decor, dinnerware and cutlery together. Original and discarded variants are not overwritten.

The homepage and wedding page automatically choose the season using the current month in Seattle: spring March–May, summer June–August, autumn September–November, winter December–February. The browser adds falling leaves only in autumn. All decorative motion respects reduced-motion preferences and can be paused.
